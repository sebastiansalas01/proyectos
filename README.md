# Proyectos

Web app instalable con los proyectos del equipo. Se publica con GitHub Pages: el enlace es siempre el mismo y cada cambio en este repositorio aparece en la app.

## Proyectos

- **Business Plan Ecom (Colombia)** – `business-plan-ecom.html`: accesorios de paseo para perro, prueba de humo con 3 productos, investigación de Colombia y Corea, calculadora de márgenes, anuncios y landings de ejemplo.

## Instalar en el móvil

- iPhone (Safari): Compartir → Añadir a pantalla de inicio.
- Android (Chrome): menú ⋮ → Instalar app.

## Comentarios de voz

El botón del micrófono (abajo a la derecha) dicta el comentario y lo envía al grupo de WhatsApp. En Safari, si el micrófono de la página no está disponible, se usa el micrófono del teclado.

## Archivos

- `index.html` – inicio con la lista de proyectos.
- `business-plan-ecom.html` – el plan.
- `voice.js` – botón de comentarios de voz.
- `manifest.webmanifest`, `sw.js`, `icon-*.png` – instalación como app.
- `*.jpg` – imágenes de concepto generadas con IA (no son fotos del producto final).
